# KRK Sahne 2

Mobil Kâbe ve Halay sahneleri. GitHub Pages statik arayüzü; Railway üzerinde TikTok LIVE olay dinleyicisi.

## Backend

Railway ile bu depoyu bağlayın. Start: `npm start`. İsteğe bağlı `TIKTOK_USERNAME=krkmedya`.

`/health` bağlantı durumunu, `/events` Server-Sent Events üzerinden yorum ve hediyeleri döndürür.

TikTok-Live-Connector resmi olmayan bir kütüphanedir; canlı yayın açık değilken bağlanamaz ve API değişikliklerinden etkilenebilir.
